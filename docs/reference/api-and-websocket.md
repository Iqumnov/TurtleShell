## 2. REST API Endpoints

### 2.1 Reconfigure Simulation
- **POST** `/api/simulation/configure`
- **Payload**:
  ```json
  {
    "qpu_type": "heron",
    "ion_species": "Ca40",
    "n_ions": 20,
    "tenant_count": 3,
    "scheduling_algo": "spectral",
    "active_scenario": "crosstalk",
    "crosstalk_intensity": 80.0,
    "defense_l1": true,
    "defense_l2": true,
    "defense_l3": true,
    "defense_l4": true
  }
  ```
- **Response**: `{"status": "ok", "configured": true}`

### 2.2 Reset Simulation State
- **POST** `/api/simulation/reset`
- **Response**: `{"status": "reset_success"}`

### 2.3 Health Check
- **GET** `/health`
- **Response**: `{"status": "healthy", "version": "0.1.0"}`
